# デモ台本（3分）

公開URL: （Vercelデプロイ後に記入）／ローカル: http://localhost:3000

## 0. つかみ（20秒）

> 「目標が続かへん理由って、意志が弱いからやと思ってません？ 違います。**誰も見てへんから**です。」
> 「そこで、自分以上に自分を知ってるAIに、見張ってもらうことにしました。**AIおかん**です。」

## 1. 過去を渡す（30秒）

- 画面1で「AIおかんに渡す」を押す
- 言うこと：「Gmailのエクスポート、Xのアーカイブ、LINEのトーク履歴。**どれも今日誰でもエクスポートできる実在の形式**です。今日は2年分36件を入れています」

## 2. 見立て（60秒）★ここが山場

- 生成された3つの指摘を**声に出して読む**
  - 「入会だけが得意：2025年1月にジム入会して20か月で来店11回」
  - 「開始日を未来にずらす：来週から本気出す、を2年で7回」
- 言うこと：「**褒めてくれるAIは世の中にたくさんあります。これは言い当ててくるAIです**」
- 決め台詞を読む：「やる気がないんちゃう。見張りがおらんだけや」

## 3. 約束（30秒）

- 目標・期限・証拠・罰金を入れる
- 言うこと：「ポイントは**罰金額を本人に決めさせる**こと。押し付けられた制限は続きませんが、自分で結んだ約束は効きます」

## 4. 監視と制裁（40秒）★見せ場は「回数を数える」

用意するもの: 腕立て伏せの動画を2本（**10回やりきったもの**と、**途中で潰れたもの**）。どちらも20秒以内。

- 約束は「腕立て伏せを10回やる」にしておく（文面に「10回」と入れるのが条件。ここから必要回数を読む）
- まず**足りないほう**を出す → 「数えられた回数：4回 / 約束は10回」が出て `話にならん`
  - 言うこと：「**写真なら『やった感』でごまかせますが、動画は回数まで数えられます**。あと2回、と数字で詰めてきます」
- 次に**やりきったほう**を出す → 「数えられた回数：10回」で `認めたる`
- 関係ないものを出して「怪しい」と判定されるのも短く見せる
- 「期限切れにする（デモ用）」を押して罰金画面 → おかんの説教を読む
- 言うこと：「10秒の動画を10コマ/秒、約100コマで見ています。画面の『解析対象』に、実際に何を何コマで見たのかが出ます」
- 実機の動画で検証済み（10.7秒10回→10回でok、5.7秒で潰れる→4回でng。いずれも3回連続で同じ結果）

## 締め（20秒）

> 「10年後、記録は人が意識せんでも**自動で入ります**。ウェアラブル、写真、音声。そのとき必要になるのは、集めたデータで**人を動かす仕組み**です。AIおかんはその入口です。」

## 審査基準への当て方（聞かれたら）

| 基準 | 答え |
|---|---|
| 価値 | 「目標を管理できない」は誰もが持つ課題。既存アプリは記録が続かない |
| 実現性 | 入力は実在のエクスポート形式。判定はマルチモーダルLLMで今日動く |
| 新規性 | 褒めるAIではなく**外圧をかけるAI**。エビデンス必須化＋自己拘束の罰金 |
| AIの活かし方 | ①テキストからの人物プロファイリング ②写真・動画の真偽判定 |
| 展開性 | コミュニティ相互監視／ウェアラブル自動入力／人格の差し替え |

## 事故対策

- APIキーが無い場合は**デモモードで全ステップ通る**。画面のバッジに「デモモード（固定応答）」と出るので、聞かれたら正直に「いまはフェイルセーフの固定応答で動いています」と言う
- ただし判定だけは、AIを呼べる設定で失敗したときに固定応答を出さない（見ていない動画に判定を付けないため）。エラーが出たらもう一度提出する
- 動画が大きすぎる・回線が細い場合に備えて、**同じ動画の軽いコピー（720p・数MB）も手元に置いておく**
- 途中で詰まったらヘッダーの「AIおかん」を押すと最初に戻る
